# scripts/

Convenience wrappers around the build/deploy/demo flows. All are also available
via the [`Makefile`](../Makefile).

| Script | Purpose | Make equivalent |
|--------|---------|-----------------|
| `build.sh`  | Build the contract to Wasm (release) | `make build` |
| `deploy.sh` | Deploy the contract to Casper testnet | `make deploy` |
| `demo.sh`   | Run the AI-agent-buys-compute demo | `make agent-demo` |
