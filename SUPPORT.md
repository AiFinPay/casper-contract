# Support

Thanks for using **AiFinPay × Casper**. This page explains where to get help
and how to reach the team.

## Getting help

| I want to… | Go to |
|------------|-------|
| Ask a usage / "how do I…" question | [GitHub Discussions](https://github.com/AiFinPay/casper-contract/discussions) or open a [Question issue](https://github.com/AiFinPay/casper-contract/issues/new?template=question.yml) |
| Report a reproducible bug | [Bug report](https://github.com/AiFinPay/casper-contract/issues/new?template=bug_report.yml) |
| Request a feature | [Feature request](https://github.com/AiFinPay/casper-contract/issues/new?template=feature_request.yml) |
| Report a security vulnerability | **Do not open a public issue** — see [SECURITY.md](./SECURITY.md) |
| Learn how the system works | [ARCHITECTURE.md](./ARCHITECTURE.md) and the [README](./README.md) |
| Integrate as a merchant / agent | [`examples/`](./examples) |

## Before you open an issue

1. Read the [README](./README.md) — Quick Start, Installation, and Testing
   Instructions cover the most common setup questions.
2. Search [existing issues](https://github.com/AiFinPay/casper-contract/issues?q=is%3Aissue)
   to see if it has already been answered.
3. Confirm you are on the pinned toolchain (`rust-toolchain.toml`) and have the
   `wasm32-unknown-unknown` target installed — most build questions trace back
   to a toolchain mismatch.

## Response expectations

This repository is maintained alongside the Casper Agentic Buildathon. We aim to
triage new issues within a few business days. There is no paid support tier or
SLA — please be patient and provide as much detail as possible (OS, toolchain
version, exact command, and full output) so we can help quickly.
